# Мобільна адаптація десктопного дизайну

Мета: мобільна версія виглядає як той самий сайт — ті самі шрифти, кольори, форми, тон, — але зручна для скролу пальцем.

## Принципи
- Не вигадуй нового стилю. Береди токени (кольори, шрифти, радіуси, тіні) з десктопу.
- Одна колонка. Порядок блоків — за пріоритетом змісту, а не за візуальним порядком десктопа.
- Ієрархія зберігається: заголовок → підзаголовок → ключова дія. Головна кнопка видима без зайвого скролу.
- Кожна секція має чіткий початок: достатній вертикальний відступ, а не склеєні блоки.

## Розміри (ширина макета 375 або 390 px)
- Бокові поля 16–20 px. Gap між блоками з сітки 4/8.
- Зони натискання не менші за 44×44 px, відступ між ними не менше 8 px.
- Основний текст не менше 16 px, міжрядковий інтервал 1.4–1.6. Заголовки зменшуй пропорційно (h1 приблизно 28–36 px).
- Довгі рядки на десктопі стають вузькими блоками на мобільному; обмежуй довжину рядка 35–45 символів.

## Що робити з типовими блоками
- Горизонтальне меню → бургер або компактна шапка.
- Сітка 3–4 колонки → одна колонка або горизонтальна карусель, якщо блоки схожі.
- Два стовпці «текст + картинка» → картинка над текстом (або під, якщо картинка допоміжна), текст на всю ширину.
- Таблиці й широкі елементи → горизонтальний скрол усередині блока або перетворення на список карток.
- Hover-ефекти → замінити на стани натискання.

## Перевірка скролу
Прогорни сторінку «пальцем» зверху вниз: на кожному екрані має бути зрозуміло, де ти, що важливо і що робити далі. Нічого не обрізається, горизонтального скролу сторінки немає.

## Реалізація у Figma
Створюй мобільні фрейми з Auto Layout (див. скіл `figma-autolayout-wordpress`), використовуй ті самі компоненти й змінні (variables) стилів. Показуй користувачу скріншот і чекай підтвердження перед масовими змінами.
