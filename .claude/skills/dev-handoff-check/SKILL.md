# Перевірка перед передачею розробнику

Пройди по файлу й відповідай «є / нема / частково» по кожному пункту, не змінюючи нічого без дозволу.

## Структура
- Усі секції — фрейми з Auto Layout, без Group і вільного позиціювання.
- Назви шарів відповідають конвенції `тип/назва` (див. `figma-autolayout-wordpress`); жодних «Frame N».
- Повторювані блоки — компоненти.

## Стилі й токени
- Кольори, шрифти, радіуси, відступи — змінні (variables) або стилі, а не значення «на око».
- Відступи кратні 4/8; ті самі відступи між однаковими секціями.

## Адаптив
- Є фрейми десктопа й мобільної версії (і планшета, якщо потрібно) з однаковими компонентами.
- Зони натискання від 44 px, текст від 16 px на мобільному.

## Доступність
- Контраст тексту: від 4.5:1 для звичайного, від 3:1 для великого.
- Не передавай інформацію лише кольором; є стани для кнопок і полів (hover, focus, disabled).

## Підсумок
Склади для користувача короткий звіт: що в порядку, що виправити, що вирішує розробник. Виправлення вноси тільки після підтвердження.
